SHUBHX VISION — PREMIUM DATA INTELLIGENCE STUDIO

Includes:
- Premium glassmorphism UI with depth, gradient lighting, blur and hover effects
- ☀️ Light button switches to light mode; 🌙 Dark button switches to dark mode
- CSV / XLSX / XLS upload and sample dataset
- Overview KPIs, preview, missing-value chart and column profile
- Cleaning: missing values, duplicate removal, IQR outliers, text cleanup and type conversion
- Analysis: histogram, box, violin, scatter, bar, line, pie, area, correlation and group-by
- Data Lab: statistics, filtering, calculated columns and reproducible sampling
- Export Center: CSV, Excel and JSON report
- AI assistant: local data-aware answers; optional Gemini API

WINDOWS INSTALL:
1. Extract ZIP and open PowerShell in the folder containing app.py.
2. py -3.15 -m venv venv
3. .\venv\Scripts\python.exe -m pip install --upgrade pip
4. .\venv\Scripts\python.exe -m pip install -r requirements.txt
5. .\venv\Scripts\python.exe -m streamlit run app.py

Do not run python app.py or use VS Code Run Python File.
Optional Gemini: copy .env.example to .env and add your API key. Never share the key.
Python syntax is checked. Live Gemini calls require a valid key and network.
